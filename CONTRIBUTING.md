# Contributing

Contributions to public documentation, tests, and independently authored examples are welcome.

Open an issue describing the problem and the evidence for any claimed functionality. For code contributions, use a pull request with a concise summary, test steps, and licensing provenance. Do not submit secrets, personal data, private project content, or third-party code without redistribution rights.

The repository currently has no explicit open-source license. Until licensing is reviewed and added, do not assume permission to redistribute or reuse its contents beyond rights granted by applicable law.
